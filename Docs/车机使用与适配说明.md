# BaYin Car（八音 · 安卓车机版）使用与适配说明

> 分支：`car-dev` ｜ 包名：`com.hao.bayin` ｜ 最低系统：**Android 7.0 (API 24)** ｜ 目标：720P ~ 2.5K 横屏/竖屏车机
> 构建：`.github/workflows/android-car.yml`（GitHub Actions，固定签名）
> 定位：**只做车机**，不做手机竖屏交互；曲库只来自本机与 U 盘，不再连接流媒体服务器。

---

## 一、安装

1. 打开仓库 **Actions → Android Car Build → 最新一次 run**，下载 `bayin-car-aarch64`（64 位车机）或 `bayin-car-armv7`（32 位老车机）里的 APK。
2. 车机用 U 盘/U 盘拷入 APK，用系统文件管理器点击安装；或 `adb install -r <apk>`。
3. **签名固定**：同一把 keystore 出的包，后续版本可直接覆盖安装，不会丢曲库与设置。
   keystore 只存在于仓库 Secrets（`ANDROID_KEYSTORE_BASE64` 等），**不入库**。

> 与官方手机版的关系：包名相同（`com.hao.bayin`）。若车机上已装官方版，需先卸载再安装本版
> （签名不同，Android 不允许覆盖）；反之亦然。

---

## 二、U 盘音乐怎么读（按系统版本自动适配）

打开 App 右下角 **⚙ → 外接存储（U 盘） → 选卷 → 扫描**。

| 系统 | 机制 | 说明 |
|---|---|---|
| **Android 7.0 ~ 9.0** | 传统存储模型 | 授予「存储权限」后即可直读 `/storage/XXXX-XXXX/...`，**零拷贝**扫描与播放 |
| **Android 10** | 传统模型（legacy） | 清单里已开启 `requestLegacyExternalStorage`，行为与 9.0 一致 |
| **Android 11+** | 分区存储 | 面板会提示「去授权」，跳系统页开启**所有文件访问**后即可直读 U 盘根目录 |
| 个别 ROM 收紧路径访问 | SAF 兜底 | 面板保留入口（后续版本接入 `ACTION_OPEN_DOCUMENT_TREE` + 文件描述符直读） |

**扫描策略**

- 增量：按 `(修改时间, 文件大小)` 判断，U 盘上只读变化的文件；
- 全量：面板/设置里可强制全量重扫；
- 自动：App 启动后 **60 秒**自动增量扫一次上次的目录（可在设置关闭）；
- **结果持久化**：曲库写在本机 SQLite（万首约几百 KB），重启 App 直接可播，**不会重扫**。

**拔插行为**

- 拔盘：该卷曲目置灰保留，**不会删库**；正在播放会自动暂停；
- 插回（即使盘符变化）：按卷标识恢复可用；
- 只有「卷在线且文件确实消失」且超过 10 天宽限期，才允许物理清理。

## 三、屏幕缩放与边距（针对车机大屏）

⚙ 面板 → **屏幕缩放与边距调整**，全部即时生效，无需重启：

| 项 | 范围 | 车机默认 |
|---|---|---|
| 缩放 | 70% ~ 140% | 100% |
| 字号 | 80% ~ 200% | **130%** |
| 封面尺寸 | 60% ~ 130% | **85%** |
| 屏幕上/下/左/右边距 | 0% ~ 30% | **上 7%**，其余 0 |

- 顶部被车机状态栏压住时，把「屏幕上边距」调到 6%~10% 即可避开；
- 「恢复默认」= 回到上表车机预设；
- 边距按**视口宽/高换算成像素**（CSS 的百分比 padding 以宽度为基准，直接用会算错）。

## 四、老车机 WebView 兼容

车机 WebView 常年停在 Chrome 51~83（本版在 Android 11 镜像自带 **Chrome 83** 上实测正常）。构建管线做了三层降级：

1. **CSS 值级**：`oklch()` / `lab()` / `color()` → `rgb()`（lightningcss，target chrome72）；
2. **CSS 语法级**：展开 `@layer`（Chrome <99 不认识，会导致整块样式丢失 → 白屏）、移除 `@property`（Tailwind 已用 `@supports` 兜底）、`dvh` → `vh`；
3. **JS**：esbuild 转译到 `es2017`（去 `?.`/`??`），运行时 polyfill `ResizeObserver`/`IntersectionObserver`/`flatMap`/`replaceAll`/`allSettled` 等。

另外，`html.ba-legacy`（Chrome <111）会自动关掉毛玻璃/大阴影/滤镜，减少老 GPU 掉帧。

## 五、已知限制 / 后续计划

1. **流媒体代码仍在源码里**（Navidrome / Jellyfin / Emby / Subsonic / OpenSubsonic / WebDAV / FTP / UPnP / S3 / 云盘）。
   原因：车机 UI 是上游编译产物，其页面与入口无法在不改 UI 源码的前提下去掉；
   强行删后端会让人点到那些页面就报错。**待你提供 `BaYinUI` 源码后一次性清干净**。
2. 面板是注入层实现（`src-ui/car/*`），不修改上游 React 源码；
   若后续拿到 UI 源码，建议把这些能力合并进设置页，去掉注入层。
3. SAF（`content://` + fd 直读）尚未接入，Android 11+ 目前走「所有文件访问」直读；
   若你的车机 ROM 把 U 盘路径也封死，再补这条通道。
4. 桌面端（Windows/macOS/Linux）已在本分支停用（`tauri.*.conf.json` 已删除）。

## 六、本地开发

```powershell
# 一次性环境（本机已就位：D:\AppData\DevEnv）
#   Rust 1.100 + Android targets、NDK 26.3、SDK 36、JDK 21、Node 24

# 1) 生成兼容版前端（把官方产物降级 + 注入车机层）
node tools/build-ui.js

# 2) 构建 APK（本机实测命令）
npx tauri android build --apk --target x86_64    # 模拟器
npx tauri android build --apk --target aarch64   # 车机

# 3) 模拟器验证（1920x720 / API 30）
adb install -r src-tauri/gen/android/app/build/outputs/apk/universal/debug/app-universal-debug.apk
```

关键实现位置：

| 能力 | 文件 |
|---|---|
| 车机显示设置（持久化/区间/事件） | `src-tauri/src/car/display.rs`、`src-tauri/src/commands/car.rs` |
| 卷识别与路径映射 | `src-tauri/src/car/storage.rs` |
| 卷感知曲库语义（不误删） | `src-tauri/src/car/library.rs` |
| 注入层（边距/缩放/字号/封面/侧栏/标签栏） | `src-ui/car/car.css`、`src-ui/car/car.js` |
| 设置面板 + U 盘扫描入口 | `src-ui/car/panel.js`、`src-ui/car/panel.css` |
| WebView 降级 + 嵌入资源重新打包 | `tools/build-ui.js`、`tools/css-legacy.js`、`src-tauri/build.rs` |
| 卷枚举 / 权限申请（原生） | `src-tauri/gen/android/app/src/main/java/com/hao/bayin/MainActivity.kt` |
| Rust 交叉编译任务 | `src-tauri/gen/android/buildSrc/.../BuildTask.java` |
